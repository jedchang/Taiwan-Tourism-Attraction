## Introduction

使用 Vue 實作臺灣旅遊景點導覽，串接 TDX API 所提供資訊。

## Project Description

- npm install
- npm run serve
- Node.js v14

## Use Technology & Library

- Vue CLI
- Axios
- Element-ui
- jsSHA
- jquery
- ESLint
- SCSS

## Features

- [x] 臺灣地區篩選下拉功能
- [x] 各地區風景區列表
- [x] 各地區餐飲列表
- [x] 各地區旅宿列表
- [x] RWD 版面樣式
- [x] 分頁功能
- [x] 搜尋關鍵字功能
- [x] 改串接 TDX V2.1 API
